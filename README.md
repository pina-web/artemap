# artemap · 아르떼 시공 아파트 지도

아르떼조명 시공 아파트 758곳을 파스텔 톤 전국 지도에 표시한 단일 HTML 페이지입니다.

- 상단 검색창으로 아파트명 찾기
- 지역별 목록(시도 → 시군구 → 단지)과 년월 시공 이력
- 단지별 특징(세대수·평형·시공사·시공 품목·주의사항·메모)과 시공 이력 입력
- 새 아파트 추가, JSON 백업 내보내기/불러오기, CSV 목록 내보내기

`index.html` 하나만 열면 동작합니다. GitHub Pages에서는 입력 내용이 각자의 브라우저에 저장되므로, 정기적으로 **백업 내보내기**를 해 두세요.

`data/apartments.txt` — 원본 목록(시도|시군구|아파트명|폴더 수정일|메모), `data/apartments.json` — 좌표 포함 데이터.
